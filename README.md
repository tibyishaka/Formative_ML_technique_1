# Milan Mobile Network Traffic Forecasting

Formative assignment: comparative analysis of three sequential models (seasonal-decomposition + ARIMA,
LSTM, GRU) for one-step-ahead mobile network traffic forecasting on the Milan telecom dataset.

## Files in this project

| File | What it is |
|---|---|
| `Milan_Traffic_Forecasting.ipynb` | The experiment notebook. Downloads the dataset, runs the exploratory analysis, tunes and trains the three models, and saves every figure/table it produces. |
| `figures/` | Created by the notebook. Six PNG figures. |
| `results/` | Created by the notebook. CSV/JSON files with every numeric result (memory-usage evidence, tuning logs, performance tables, timing, hardware info). |
